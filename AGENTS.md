# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This project targets **SDK 54**, not the newest SDK. Expo Go on the iOS App Store
is capped at 54.0.2 (checked 2026-08-26); Expo only publishes newer clients
(57.x) for simulators. Testing on a real iPhone therefore requires SDK 54.

Move to a newer SDK only when the App Store build catches up, or when the app
switches to an EAS development build instead of Expo Go.
