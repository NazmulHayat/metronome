# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v58.0.0/ before writing any code.

This project targets **SDK 58**. Expo Go on the iOS App Store only supports the
latest SDK (58.0.0, checked 2026-10-27), and older Expo Go builds cannot be
installed on a real iPhone. When the App Store Expo Go moves to a new SDK, the
project has to be upgraded to match, or the phone shows "Project is
incompatible with this version of Expo Go".

To stop depending on the Expo Go version, switch to an EAS development build.
